# Agent Board Slice Plans

Slice plans describe a branch of related work: direction and guardrails for many
task records. The slice plan explains direction; the task record controls the
exact runnable scope.

Read order for a fresh agent:

1. `AGENTS.md`
2. `WORKFLOW.md`
3. `PROJECT.md`
4. `CONTEXT.md`
5. `docs/agents/project-master-plan.md`
6. the relevant slice plan in this folder
7. the linked task record under `docs/agents/tasks/`
8. `.t3/agent-board.json`
